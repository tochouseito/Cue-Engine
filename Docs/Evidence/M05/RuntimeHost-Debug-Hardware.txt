The Configured probe requests Standard validation and DRED. Exit Code 0 verifies that diagnostics are
allowed by the Debug build and that Debug Layer and DRED enabled status match interface availability.

The 300-frame command was rerun with stdout and stderr retained together. The following PowerShell was
used to capture the process result and evaluate each scan:

$runtimeOutput = @(
    & $runtime --render-smoke hardware --width 1280 --height 720 2>&1 |
        ForEach-Object { "$_" }
)
$runtimeExit = $LASTEXITCODE

$fallbackPatterns = @(
    'D3D12 DREDを利用できないため診断なしで続行します',
    'D3D12 Debug Layerを利用できないため診断なしで続行します',
    'D3D12 InfoQueueを利用できないため診断なしで続行します',
    'D3D12 InfoQueueのBreak Policyを設定できないため診断なしで続行します',
    'D3D12 InfoQueueのWarning Policyを設定できないため診断なしで続行します',
    'D3D12 Live Object診断Interfaceを取得できません',
    'D3D12 Live Object診断を実行できません'
)

foreach ($pattern in $fallbackPatterns)
{
    @($runtimeOutput | Select-String -SimpleMatch $pattern).Count
}

@($runtimeOutput | Select-String -Pattern '\[Error\]').Count
@($runtimeOutput | Select-String -Pattern 'DeviceRemoved').Count
@($runtimeOutput | Select-String -Pattern 'Device Removal').Count
@($runtimeOutput | Select-String -Pattern 'D3D12\.DRED').Count
