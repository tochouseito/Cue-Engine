Some 3D scan models used in this project are third-party test assets from
The Stanford 3D Scanning Repository, including Stanford Bunny, Happy Buddha,
Stanford Dragon, and Asian Dragon / XYZ RGB Dragon.

These models are used only for rendering, GPU culling, LOD, lighting, and
performance testing. The evaluated work is the rendering engine and related
graphics systems, not the 3D model assets.

本作品では、描画エンジン、GPU Driven Rendering、カリング、LOD、ライティング、
パフォーマンス検証用アセットとして、Stanford 3D Scanning Repository の
Stanford Bunny / Happy Buddha / Stanford Dragon、および XYZ RGB Inc. source の
Asian Dragon を使用しています。

これらの3Dモデルは検証用アセットであり、評価対象は3Dモデル制作ではなく、
描画エンジンおよび関連するグラフィックス技術の実装です。
